# Alert

A message that stays on the page: what happened, what is about to, or what to do about it. Its
status, one of five, sets its tint, its mark and its title's colour, so the reader knows how much
it matters before reading a word.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Something the reader should know while on this page:** a trial ending, stock running low, a
  payment that failed.
- **What a form or an action left wrong,** listed above it.
- **A note that belongs with something,** such as the buyer's request on an order.

For a message that passes, use a Toast. To ask before something that cannot be undone, use an
AlertDialog.

## Import

```tsx
import { Alert, CloseButton } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Alert status="warning">
  <Alert.Indicator />
  <Alert.Content>
    <Alert.Title>Running low</Alert.Title>
    <Alert.Description>Only 3 silk scarves are left.</Alert.Description>
  </Alert.Content>
  <CloseButton aria-label="Close" />
</Alert>
```

## Accessibility

The marks are decorative, hidden from a screen reader: the title says what the status means. An
alert drawn with the page is read with it; one that appears later needs a role to be announced.
Give a close button a name, such as "Close".

## Styling

`.alert` and `.alert--default`, `--accent`, `--success`, `--warning`, `--danger`;
`.alert__indicator`, `.alert__content`, `.alert__title`, `.alert__description`. Its tint is
`--alert-tint`, mixed from the status's colour and the surface, so a theme that changes either
changes it.
