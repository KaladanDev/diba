# Fieldset

A titled group of fields in a form: a product's price and stock, a buyer's delivery address. Its
legend names the group, for the eye and for a screen reader, and its fields stand together under
it.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A long form in parts,** such as a product's details, then its price and stock.
- **Fields that answer one question,** such as the parts of an address.

Not for a single field: its label is enough. Not for a choice among options: a RadioGroup or a
CheckboxGroup names its own group.

## Import

```tsx
import { Description, Fieldset } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Fieldset>
  <Fieldset.Legend>Price and stock</Fieldset.Legend>
  <Description>What a buyer pays, and how many are left.</Description>
  <Fieldset.Group>{/* the fields */}</Fieldset.Group>
  <Fieldset.Actions>{/* buttons, if the group saves alone */}</Fieldset.Actions>
</Fieldset>
```

## Accessibility

It is a `fieldset`, named by its legend: a screen reader says the group's name as it enters the
first field. Each field still needs its own label.

## Styling

`.fieldset`, `.fieldset__legend`, `.fieldset__field-group` and `.fieldset__actions`.

## As a block

A tree draws the same group in a Form block, on the web and in Flutter: its `legend`, its
`description`, then its fields.
