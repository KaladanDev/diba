# Spacer

Room between two things, on purpose: where a stack's single gap is not the space you want, such as
before a form's buttons. It draws with its own styles, so a page needs no utility classes for it.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **One space larger than the rest,** such as a form's buttons set apart from its fields.
- **A push across a row,** between two things that a gap would not separate enough.

Not for even spacing: a Stack's `gap` does that. Not to push something to the far end: use a
Stack's `justify`.

## Import

```tsx
import { Spacer } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Field />
<Spacer size={4} />
<Button>Save</Button>
```
