# Menu

A Dropdown's menu standing on the page: an order's actions in a side panel, a list's sort order,
always in sight. Its items and sections are the Dropdown's.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A panel's actions,** a few, always shown: print the invoice, add a note, cancel the order.
- **A choice beside a list** that changes how it shows: sort by, what to show.

For actions behind a button, use a Dropdown; for a choice that is a form's value, a ListBox, a
RadioGroup or a Select.

## Import

```tsx
import { Header, Label, Menu, Separator } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Menu aria-label="Order actions" onAction={(key) => …}>
  <Menu.Item id="invoice" textValue="Print the invoice">
    <Printer />
    <Label>Print the invoice</Label>
  </Menu.Item>
  <Separator />
  <Menu.Item id="cancel" variant="danger">Cancel the order</Menu.Item>
</Menu>
```

## Accessibility

The menu is named by its `aria-label`; each item is a menu item, and a chosen one is read as
checked. The keyboard reaches the menu once, then moves within it.

## Styling

`.menu`; `.menu-item` with `--default` and `--danger`, and `__indicator`; `.menu-section`;
`[data-selected]`, `[data-focus-visible]`, `[data-hovered]` and `[data-disabled]`.
