# TimePickerDialog

A time picked on a clock's dial, in a dialog over the page: the hour, then the minute, with OK to
keep it. It asks a time as Flutter's does, so an app's web and phone ask it alike, and it can be
typed instead with the keyboard button.

<Controls of={Stories.Playground} />

## When to use it

- **A time picked rather than typed,** from a button or a field that shows it: a delivery slot, a
  reminder.
- **After a day,** to ask its time, as a date picker at a minute does in a tree.

To type a time in the page, use a TimeField.

## Import

```tsx
import { TimePickerDialog, type TimeOfDay } from '@kaladan/diba-react'
```

## Anatomy

The dialog is one component, open while `isOpen` is true:

```tsx
const [open, setOpen] = useState(false)
const [time, setTime] = useState<TimeOfDay | null>({ hour: 14, minute: 30 })

<Button onPress={() => setOpen(true)}>14:30</Button>
<TimePickerDialog
  isOpen={open}
  onOpenChange={setOpen}
  value={time}
  onConfirm={(picked) => {
    setTime(picked)
    setOpen(false)
  }}
/>
```

It holds the words over the clock, the hour and the minute in two boxes, AM and PM on a 12-hour
clock, the dial, and Cancel and OK; the keyboard button swaps the dial for two fields to type in.

## Values

A time here is `{ hour, minute }`, the hour 0 to 23 whatever clock draws it. To keep it as
`@internationalized/date`'s `Time`, `new Time(hour, minute)`.

## Accessibility

The dialog is named by its words, «انتخاب ساعت», and takes the focus when it opens. The dial is a
slider, read with what it picks and its value; the boxes and the keyboard button have their names.
A typed time that is not one says so at once.

## Styling

`.time-picker`, its theme the page's: the dial and the picked hour in the brand's colours.

## As a block

A tree's TimeField block is a field reading «۱۴:۳۰» whose press opens this dialog; a DateField or
DateRangePicker block at an hour or a minute opens it after its days.
