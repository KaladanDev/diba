# Slider

A value, or a range, along a track: a discount, a price range in a filter, a stock level to be
told at. It is Material's slider on both platforms, drawn as Flutter's.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A value whose place in a range matters more than its digits:** a discount up to half, a
  rating, a level.
- **A range to filter by:** prices from and to.

For an exact figure the reader types, a price or a quantity, use a NumberField.

## Import

```tsx
import { Description, Label, Slider } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Slider defaultValue={30} maxValue={50} step={10}>
  <Label>Discount (%)</Label>
  <Slider.Output />
  <Slider.Track>
    {({ state }) => (
      <>
        <Slider.Fill />
        {state.values.map((_, i) => (
          <Slider.Thumb key={i} index={i} />
        ))}
      </>
    )}
  </Slider.Track>
  <Description>…</Description>
</Slider>
```

## Examples

### One value and a range

A `defaultValue` or `value` of two numbers draws two thumbs; the fill lies between them, and
neither passes the other.

<Canvas of={Stories.Range} />

### Steps

`step` is what each move takes, 1 by default. Given one, a dot marks each step while they are 6 or
more apart on the track; a fine step draws none.

<Canvas of={Stories.Steps} />

### Formats

`formatOptions` are `Intl.NumberFormat`'s and write the value in the page's digits. A percent
takes a fraction: 0.25 is 25%. Toman has no currency code: write it as a whole number and name the
unit in the label, as «(تومان)».

<Canvas of={Stories.Formats} />

### Without its value, with help, disabled

Leave out `Slider.Output` where the place on the track says enough, and name the slider with
`aria-label` where it has no label. Disabled, it is drawn at half.

<Canvas of={Stories.States} />

## What it builds

`onChange` fires as the thumb moves; `onChangeEnd` once it is let go, which is when a filter
should ask the server.

`Slider.Thumb` takes its `index` and a `name`, which sends its value in a form. `Slider.Output`
takes a function of the state for words of your own. Every part takes its element's own props
too, and a `className`.

## Accessibility

Each thumb is a slider named by the `Label`, its value read as the output writes it, «۲۵٪». A
range's two thumbs say which end each is before the label, «کمترین» and «بیشترین», Minimum and
Maximum; a thumb's own `aria-label` says otherwise. The track takes a press too, moving the nearest
thumb there.

## Styling

`.slider` with `__output`, `__track`, `__fill`, `__thumb` and `__steps`; `[data-dragging]`,
`[data-focus-visible]` and `[data-disabled]`. The ring is `--slider-thumb-ring`.

## As a block

A tree draws the same slider, on the web and in Flutter, `isRange` giving two thumbs, and writes
its value as the NumberField does: `formatStyle` `percent` a share of the range, `currency: "IRT"`
toman with its word.
