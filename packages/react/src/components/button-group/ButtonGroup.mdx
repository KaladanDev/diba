# ButtonGroup

Buttons joined into one: their inner corners squared, the two ends round, a thin separator between
them if you like. For actions that belong together, such as previous and next, or a main action and
a menu of the others.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Two directions of one move:** previous and next, zoom out and in.
- **A row's few actions,** close together: edit, duplicate, delete.
- **A split button:** the main action, and a menu of the others beside it.

To choose one or several of a set, where the choice stays pressed, use a ToggleButtonGroup. For a
bar of mixed controls that the arrow keys move along, use a Toolbar.

## Import

```tsx
import { Button, ButtonGroup } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<ButtonGroup aria-label="Pages" variant="secondary">
  <Button>Previous</Button>
  <Button>
    <ButtonGroup.Separator />
    Next
  </Button>
</ButtonGroup>
```

## Accessibility

A group is a `group` to a screen reader: name it with `aria-label` for what its buttons have in
common, "Pages", and each icon-only button for what it does. The separators are hidden.

## Styling

`.button-group` with `.button-group--horizontal`, `--vertical` and `--full-width`;
`.button-group__separator`.

## As a block

A tree draws the same group, on the web and in Flutter, its Buttons as its children. Its `variant`
is `secondary` and its `size` `sm` unless the tree says otherwise, as a Button's are.
