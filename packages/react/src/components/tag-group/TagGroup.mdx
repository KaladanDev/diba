# TagGroup

Tags in a row that wraps: a product's keywords, a list's filters, the labels a product carries.
They may only show, be chosen, one or several, or be removed. A tag is Flutter's chip on both
platforms.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Short words a reader adds and removes:** keywords, the sizes a product comes in.
- **Quick filters over a list,** several on at once.
- **Labels that only show:** new, handmade, a category that opens its page.

For a choice in a form, use a CheckboxGroup or a RadioGroup; for a status, a Chip.

## Import

```tsx
import { Label, Tag, TagGroup } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<TagGroup selectionMode="multiple" onRemove={(keys) => …}>
  <Label>Filters</Label>
  <TagGroup.List>
    <Tag id="sale">On sale</Tag>
    <Tag id="gift">
      <Gift />
      Gift
    </Tag>
  </TagGroup.List>
  <Description>…</Description>
</TagGroup>
```

## Examples

### Sizes

`sm`, `md` and `lg` are 28, 32 and 36 tall, with Flutter's room for a tap above and below.

<Canvas of={Stories.Sizes} />

### Choosing

With no `selectionMode`, tags only show, and take no hover. One chosen, or several: a chosen
tag is gilt, a tick at its start. `disallowEmptySelection` keeps one chosen.

<Canvas of={Stories.Choosing} />

### Removing

`onRemove` gives each tag a remove button; it takes the keys to remove. Backspace or Delete
removes the tag with the focus. `renderEmptyState` on the list says what an empty group holds.

<Canvas of={Stories.Removing} />

### Icons and links

An icon, 16, leads a tag's words; chosen, the tick takes its place. A tag with an `href` opens its
page, and takes the hand and a wash under the pointer as a chosen one does.

<Canvas of={Stories.IconsAndLinks} />

### Help and an error

A `Description` under the tags helps; an `ErrorMessage` says what is wrong, shown while it is.

<Canvas of={Stories.HelpAndError} />

### On a grey surface

`variant="surface"` lays tags on the surface, outlined, for a grey card.

## Accessibility

The group is a grid of tags named by its `Label`; each tag is read with whether it is chosen. Its
remove button is named «حذف برچسب» with the tag's own words after it.

## Styling

`.tag-group` and `__list`; `.tag` with `--sm`, `--md`, `--lg`, `--default` and `--surface`;
`[data-selected]`, `[data-focus-visible]`, `[data-disabled]` and `[data-href]`.

## As a block

A tree draws the same group, on the web and in Flutter; its remove buttons show when it takes
`onRemove`, which sends each removed tag's id. Its help and error are drawn under it.
