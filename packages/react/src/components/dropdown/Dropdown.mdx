# Dropdown

A menu behind a button: a product's actions, a row's, the columns a table shows. It opens from its
button, and only from it; an item does its action and closes it.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Actions that would crowd a toolbar or a row:** edit, duplicate, export, delete.
- **A quick choice that is not a form's value:** which columns show, a sort order.

For a value sent with a form, use a Select; for actions always in sight, a Menu or buttons.

## Import

```tsx
import { Button, Dropdown, Header, Label } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Dropdown>
  <Button variant="secondary">Actions</Button>
  <Dropdown.Popover placement="bottom end">
    <Dropdown.Menu onAction={(key) => …}>
      <Dropdown.Item id="edit" textValue="Edit">
        <Pencil />
        <Label>Edit</Label>
      </Dropdown.Item>
      <Dropdown.Section>
        <Header>Danger</Header>
        <Dropdown.Item id="delete" variant="danger">Delete</Dropdown.Item>
      </Dropdown.Section>
    </Dropdown.Menu>
  </Dropdown.Popover>
</Dropdown>
```

## Examples

### Open

`placement="bottom end"` lines the menu's end up with the button's, the usual place for a
toolbar's last button or a row's actions.

<Canvas of={Stories.Open} />

### Choosing

With `selectionMode` on the menu, its items are choices: each chosen one is on the neutral fill,
with no tick, as Flutter's menu marks it. With `multiple`, the menu stays open between them.

<Canvas of={Stories.Choosing} />

### A submenu

`Dropdown.SubmenuTrigger` holds an item and the popover it opens; the item takes a
`Dropdown.SubmenuIndicator`.

## Accessibility

The button says it opens a menu; the menu is named by it, and each item read with its place. An
icon-only button needs its name, and a row's should say which row.

## Styling

`.dropdown`, `__trigger`, `__popover` and `__menu`; `.menu-item` with `--default` and `--danger`;
`[data-open]`, `[data-selected]`, `[data-focus-visible]` and `[data-disabled]`.

## As a block

A tree draws the same dropdown, on the web and in Flutter, its `trigger` slot a Button, its items
`DropdownItem`s with an `icon` and a `description`, and titled `DropdownSection`s.
