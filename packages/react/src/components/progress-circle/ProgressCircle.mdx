# ProgressCircle

How far along something is, as a ring: a shop's setup, a photo uploading. Small enough to sit
beside words or on a thumbnail.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Progress in little room,** such as on a photo's thumbnail while it uploads.
- **A share of a whole beside its words,** such as a shop's setup, 3 of 5 steps.

Not where there is room for a label and a value: use a ProgressBar. Not for a wait with no
measure that needs no room of its own: a Spinner says it more plainly.

## Import

```tsx
import { ProgressCircle } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<ProgressCircle value={60} aria-label="Shop setup">
  <ProgressCircle.Track>
    <ProgressCircle.TrackCircle />
    <ProgressCircle.FillCircle />
  </ProgressCircle.Track>
</ProgressCircle>
```

## Accessibility

It is a `progressbar`, named by its `aria-label` or the words it is labelled by, its value read as
a percent. An indeterminate one has no value.

## Styling

`.progress-circle` with `--sm`, `--md`, `--lg` and its colour; `.progress-circle__track`,
`__track-circle` and `__fill-circle`.

## As a block

A tree draws the same ring, on the web and in Flutter: its `value` and limits, `isIndeterminate`,
`color`, `size`, and a `label` that names it for a screen reader.
