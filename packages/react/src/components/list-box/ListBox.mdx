# ListBox

A list of options on the page: the columns of an export, a sort order, a panel's actions. It is
also the menu of a Select and a ComboBox, where its choice is highlighted instead of marked.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A choice from a list always in sight,** in a side panel or a dialog: one sort order, several
  columns.
- **A short list of actions** in a panel, each an item.

For a choice that takes little room, use a Select; for a few options in a form, a RadioGroup or a
CheckboxGroup; for actions behind a button, a Dropdown.

## Import

```tsx
import { Header, ListBox } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<ListBox aria-label="Columns to export" selectionMode="multiple">
  <ListBox.Section>
    <Header>Product</Header>
    <ListBox.Item id="name" textValue="Product name">
      <ListBox.ItemIndicator kind="choice" />
      Product name
    </ListBox.Item>
  </ListBox.Section>
</ListBox>
```

## Examples

### One choice and several

On a page, mark each option with `ListBox.ItemIndicator kind="choice"`: a radio for
`selectionMode="single"`, a checkbox for `multiple`, as Flutter's list tiles mark them. The chosen
option has no fill of its own; its mark says so.

<Canvas of={Stories.Choices} />

### Actions

With no `selectionMode`, each item is an action, and `onAction` says which was pressed. An icon
leads each; `variant="danger"` draws one in the danger colour, last, for what cannot be undone.

<Canvas of={Stories.Actions} />

### Sections and disabled options

`disabledKeys` keeps options from being chosen or pressed; they are drawn at half.

<Canvas of={Stories.Sections} />

### Nothing in it

`renderEmptyState` says what a list with no options holds.

## Accessibility

The list is a list box named by its `aria-label`; each option is read with its place, and whether
it is chosen. A choice's mark is drawn, not read twice: the option itself is chosen.

## Styling

`.list-box`; `.list-box-item` with `--default` and `--danger`, and `__indicator`;
`.list-box-section`; `[data-selected]`, `[data-focus-visible]`, `[data-hovered]` and
`[data-disabled]`.

## As a block

A tree draws the same list, on the web and in Flutter, its marks those of its `selectionMode`; an
item's `icon` or `image` leads it, its `description` is a second line, and `emptyMessage` says
when it holds nothing.
