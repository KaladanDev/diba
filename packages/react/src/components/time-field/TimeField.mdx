# TimeField

A time of day, typed hour by minute: opening hours, a delivery slot, a reminder. At rest it reads
as a clock does, «۱۴:۳۰»; in focus, its hour and minute can each be typed or stepped.

<Controls of={Stories.Playground} />

## When to use it

- **A time the reader knows and types:** when a shop opens, when a slot ends.
- **Beside a date** that is asked apart, or with no date at all.

To pick a time on a dial rather than type it, open the TimePickerDialog from a button: the block
does. For a date and a time together, use a DateField or a DatePicker at a minute.

## Import

```tsx
import { Description, FieldError, Label, TimeField } from '@kaladan/diba-react'
import { parseTime } from '@internationalized/date'
```

## Anatomy

```tsx
<TimeField defaultValue={parseTime('14:30')}>
  <Label>Delivery time</Label>
  <TimeField.Group fullWidth>
    <TimeField.Input>{(segment) => <TimeField.Segment segment={segment} />}</TimeField.Input>
  </TimeField.Group>
  <Description>Between 9 and 21.</Description>
  <FieldError />
</TimeField>
```

## Values

A time is `@internationalized/date`'s `Time`: `parseTime('14:30')`. Its `toString()` is ISO 8601,
`14:30:00`, and that is what its `name` sends in a form.

## Accessibility

Each segment is read with its name, «ساعت», «دقیقه», and its value. Typed or at rest, the field
reads as a clock, «۱۴:۳۰», on a Persian page as on an English one.

## Styling

`.time-field`, and the DateField's group classes: `.date-input-group`, `__input`, `__segment`,
`__prefix` and `__suffix`.

## As a block

A tree's TimeField block is a field whose press opens the TimePickerDialog, as Flutter's: the time
picked on a dial or typed in the dialog, not in the field. Its time is ISO 8601 on the wire,
`14:30`.
