# DatePicker

A date field with a calendar behind an icon at its end: the reader types the date, or opens the
month and picks a day. At rest it reads «۲۵ مهر ۱۴۰۵», in the reader's calendar.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A date in a form,** where the reader may type it or look for it: a delivery date, a sale's start.
- **A date and a time,** the day from the calendar and the time typed, or asked after the day.

For a span, use a DateRangePicker. For a calendar open on the page, a Calendar. For a date only
typed, never looked for, a DateField alone.

## Import

```tsx
import {
  Calendar,
  DateField,
  DatePicker,
  Description,
  FieldError,
  Label,
} from '@kaladan/diba-react'
import { parseDate } from '@internationalized/date'
```

## Anatomy

```tsx
<DatePicker defaultValue={parseDate('2026-10-17')}>
  <Label>Delivery date</Label>
  <DateField.Group fullWidth>
    <DateField.Input>{(segment) => <DateField.Segment segment={segment} />}</DateField.Input>
    <DateField.Suffix>
      <DatePicker.Trigger aria-label="Pick a date">
        <DatePicker.TriggerIndicator />
      </DatePicker.Trigger>
    </DateField.Suffix>
  </DateField.Group>
  <Description>The day the parcel leaves the warehouse.</Description>
  <FieldError />
  <DatePicker.Popover>
    <Calendar aria-label="Delivery date">{/* the Calendar's parts */}</Calendar>
  </DatePicker.Popover>
</DatePicker>
```

## Values

A DatePicker's values are `@internationalized/date`'s, as a DateField's are: `parseDate` for a
day, `parseDateTime` for a day and a time. Its `toString()` is Gregorian ISO 8601 whatever calendar
draws it, and so is what its `name` sends in a form.

## Accessibility

The field is named by its `Label`; name the trigger, "Pick a date", since it is an icon alone. The
calendar is a dialog: it takes the focus when it opens and gives it back when it closes.

## Styling

The DateField's classes, and `.date-picker`, `.date-picker__trigger`,
`.date-picker__trigger-indicator` and `.date-picker__popover`.

## As a block

A tree's DateField block is this picker. At an hour or a minute, the day it picks asks its time in
the time picker. Its dates are Gregorian ISO 8601 on the wire, whatever calendar draws them.
