# Spinner

Something is on its way and there is no telling how long it will take: a card's figures, a
search's results. Two arcs turn over a ring once every 750ms.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A part of the page loading,** such as a card's figures, where they will be.
- **A wait with words,** small beside them, such as "Saving…".

Not for a wait you can measure, such as an import's rows: use a ProgressBar. Not inside a button:
a Button's `isPending` draws its own. Not for a whole page that is still to come: draw its shape
with skeletons instead.

## Import

```tsx
import { Spinner } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Spinner />
```

One arc solid and fading, one clear and rising, over a ring in the off-track shade. It holds still
when the reader asks for less motion.

## Accessibility

It is a `status`, named "Loading" in the page's language unless an `aria-label` says more, such
as what is loading.

## Styling

`.spinner` with `--sm` to `--xl` and its colour, `--accent` and the rest; its ring is the theme's
off-track shade.

## As a block

A tree draws the same spinner, on the web and in Flutter: its `size`, `color`, and a `label` for a
screen reader, "Loading" in the page's language when it has none.
