# Blocks

Every component a tree may name is a block, with its props, children, slots and events in the
manifest; each component's own page ends with its block. These are the sample trees both renderers
are tested against, the same file the Flutter gallery draws, in the page's language. The props on
each are in its tree; the trees are in `packages/schema/fixtures/samples.json`.
