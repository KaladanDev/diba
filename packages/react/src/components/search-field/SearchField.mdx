# SearchField

A field for searching: a search icon at its start, the words, and a button at its end that empties
it. Enter sends the words; Escape empties the field.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Narrowing a list or a table:** products by name or code, orders by number or buyer.
- **Searching a page or a store,** sent with Enter.

For words the reader writes to keep, a name or a note, use a TextField.

## Import

```tsx
import { SearchField } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<SearchField aria-label="Search products">
  <SearchField.Group>
    <SearchField.SearchIcon />
    <SearchField.Input placeholder="Name or code" />
    <SearchField.ClearButton />
  </SearchField.Group>
</SearchField>
```

## Examples

### With and without a label

Where the page already says what is searched, above a list of products, name the field with
`aria-label` and leave the label out. In a form, give it a `Label`, and help in a `Description`.

<Canvas of={Stories.WithLabel} />

### Enter and clear

`onSubmit` takes the words when Enter is pressed. The clear button and Escape empty the field and
call `onClear`; the focus stays in it.

<Canvas of={Stories.SubmitAndClear} />

### Empty, written in, disabled, read-only, invalid, on a grey surface

Read-only, its words can be selected but not changed, and the clear button is dimmed.

<Canvas of={Stories.States} />

### Width

In a column it is the column's width. In a row beside a button it is as wide as its parts, about
230; `fullWidth` gives it what the rest of the row leaves.

## Accessibility

The input is a search box, named by its `Label` or its `aria-label`. The icon is hidden from a
screen reader. The clear button is named in the page's language and is left out of the Tab order:
Escape does its work from the keyboard.

## Styling

`.search-field` with `--primary`, `--secondary` and `--full-width`; `__group`, `__input`,
`__search-icon` and `__clear-button`; `[data-empty]`, `[data-invalid]`, `[data-disabled]` and
`[data-focus-within]` on the group.

## As a block

A tree draws the same field, on the web and in Flutter, its label hidden unless it says
`isLabelHidden: false`. The icon and the clear button are always there.
