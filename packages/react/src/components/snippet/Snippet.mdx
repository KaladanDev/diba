# Snippet

Words someone is meant to copy, with the button that copies them: a key, an address, a code, a
command. They run left to right on a Persian page too, with the copy button at the frame's end, and
what lands on the clipboard is exactly the words, never the prompt drawn before them. It draws with
its own styles, so a page needs no utility classes for it.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A key or an address** an app or a developer has to paste somewhere else.
- **A code a buyer types elsewhere,** such as a discount code for the cart.
- **A tracking number** to paste into the carrier's site.
- **A command** in a developer's instructions.

For words that are only read, use Text. For a value someone edits, use a TextField.

## Examples

### Variants

`default` lies on the second surface; `secondary` is outlined in the border's colour, with no
fill. The words are the page's ink on both.

<Canvas of={Stories.Variants} />

### On a grey card

On a grey card the second surface is the card's own grey, so a default snippet takes the surface
there and keeps its frame.

<Canvas of={Stories.OnGrey} />

### Sizes

`sm`, `md` and `lg`: 8 by 4, 12 by 6 and 16 by 8 in. The words stay 14 on 21 at every size.

<Canvas of={Stories.Sizes} />

### The prompt

There is none unless `symbol` gives one: `$` for a command, or another shell's. A key, an address
or a code has none. `hideSymbol` drops one that is given.

<Canvas of={Stories.Prompts} />

### Several lines

Give an array, a line each. They are copied as one block, the newlines kept. The copy button stays
at the top end, level with the first line, and the last line sits as far from the frame's foot as
the first from its head.

<Canvas of={Stories.SeveralLines} />

### What is copied

`copyText` is copied in place of the words shown, for a key shown in part. `onCopy` is called with
it once the browser has taken it. `hideCopyButton` leaves only the words.

<Canvas of={Stories.Copying} />

### Too long for its box

It scrolls inside its frame rather than wrapping, since a key broken over two lines is pasted wrong,
and the copy button stays in view.

<Canvas of={Stories.Long} />

## Accessibility

- **The copy button is named** «رونوشت» or "Copy" in the page's language, with a tooltip of the
  same words.
- **What happened is said, not only drawn:** «رونوشت شد» or "Copied" once the words are on the
  clipboard, and «رونوشت انجام نشد» or "Could not copy" when the browser refuses, where a tick alone
  would say nothing. After two seconds it offers a copy again.
- The prompt is hidden from a screen reader, as it is from the clipboard.

## As a block

A tree's Snippet is this one, on the web and in Flutter: the same two variants and sizes, no prompt
unless the tree gives one. Copying happens only on a press; `onCopy` sends the words.
