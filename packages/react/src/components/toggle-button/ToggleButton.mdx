# ToggleButton

A button that stays pressed: a product featured, a row pinned, bold on. Pressed, it is gilt with
slate-700 on it, as a checked box is.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A state shown on a button,** where the button is where the reader looks: featured, pinned,
  bold.

For one of several toggles, or several at once from a set, use a ToggleButtonGroup; for a setting
in a form or a list of settings, a Switch or a Checkbox.

## Import

```tsx
import { ToggleButton } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<ToggleButton defaultSelected>
  <Heart />
  Featured
</ToggleButton>
```

## Examples

### Off, on, disabled

`default` lies on the secondary fill when off; `ghost` has no fill until it is pressed. Pressed,
both are gilt. Disabled, it is drawn at half.

<Canvas of={Stories.States} />

### Sizes

`sm`, `md` and `lg` are 32, 36 and 40 tall, as a Button's are.

<Canvas of={Stories.Sizes} />

### Icon only

`isIconOnly` makes it a circle as wide as it is tall. Name it with `aria-label`, and say the name
in a Tooltip too, for a reader who cannot guess the icon. An icon that changes with the state, an
eye open or shut, says it twice.

## Accessibility

A screen reader meets a button read as pressed or not pressed. Its name stays the same whatever
its state: "Featured", not "Make featured" and "Unfeature".

## Styling

`.toggle-button` with `--default`, `--ghost`, `--sm`, `--md`, `--lg` and `--icon-only`;
`[data-selected]`, `[data-hovered]`, `[data-pressed]`, `[data-focus-visible]` and
`[data-disabled]`.
