# DateRangePicker

Two dates in one field, the first and the last, with a range calendar behind an icon at its end.
At rest it reads «۲۵ مهر ۱۴۰۵ – ۱ آبان ۱۴۰۵», in the reader's calendar.

<Controls of={Stories.Playground} />

## When to use it

- **A span in a form:** a sale's run, days off, a report's period.
- **A span of days and times,** from an hour on one day to an hour on another.

For one date, use a DatePicker. For a range calendar open on the page, a RangeCalendar.

## Import

```tsx
import {
  DateField,
  DateRangePicker,
  Description,
  FieldError,
  Label,
  RangeCalendar,
} from '@kaladan/diba-react'
```

## Anatomy

```tsx
<DateRangePicker>
  <Label>Sale period</Label>
  <DateField.Group fullWidth>
    <DateField.Input slot="start">
      {(segment) => <DateField.Segment segment={segment} />}
    </DateField.Input>
    <DateRangePicker.RangeSeparator />
    <DateField.Input slot="end">
      {(segment) => <DateField.Segment segment={segment} />}
    </DateField.Input>
    <DateField.Suffix>
      <DateRangePicker.Trigger aria-label="Pick dates">
        <DateRangePicker.TriggerIndicator />
      </DateRangePicker.Trigger>
    </DateField.Suffix>
  </DateField.Group>
  <Description>The sale’s first and last days.</Description>
  <FieldError />
  <DateRangePicker.Popover>
    <RangeCalendar aria-label="Sale period">{/* the RangeCalendar's parts */}</RangeCalendar>
  </DateRangePicker.Popover>
</DateRangePicker>
```

## Values

A range is `{ start, end }`, two of `@internationalized/date`'s values. Each one's `toString()` is
Gregorian ISO 8601 whatever calendar draws it; in a form, `startName` and `endName` send them.

## Accessibility

The field is named by its `Label`, and each date says whether it is the start or the end. Name the
trigger, "Pick dates", since it is an icon alone.

## Styling

The DateField's classes, and `.date-range-picker`, `__trigger`, `__trigger-indicator`,
`__range-separator` and `__popover`.

## As a block

A tree draws the same picker, on the web and in Flutter. At an hour or a minute, the two days it
picks then ask their times in the time picker, the first's and then the last's.
