# RangeCalendar

A month to pick a span of days from, drawn in the page: a first press starts it, a second ends
it, and the days between are filled. It counts in the reader's calendar, and has the Calendar's
parts.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **A span the reader picks by looking at the month:** a sale's run, a report's period, days away.
- **Where the calendar can stay open** on the page, beside a few ready periods.

For a span in a form, use a DateRangePicker: a field that opens a range calendar. For one day, use
a Calendar.

## Import

```tsx
import { RangeCalendar } from '@kaladan/diba-react'
import { parseDate } from '@internationalized/date'
```

## Anatomy

A RangeCalendar has a Calendar's parts, under its own name: `RangeCalendar.Header`,
`RangeCalendar.NavButton`, `RangeCalendar.YearPickerTrigger` with its heading, `RangeCalendar.Grid`
with its header cells and cells, `RangeCalendar.YearPickerGrid`, `RangeCalendar.MonthPickerGrid`
and `RangeCalendar.TodayButton`. See the Calendar's page for what each is.

```tsx
<RangeCalendar
  aria-label="Sale period"
  defaultValue={{ start: parseDate('2026-10-17'), end: parseDate('2026-10-23') }}
>
  <RangeCalendar.Header>
    <RangeCalendar.NavButton slot="previous" />
    <RangeCalendar.YearPickerTrigger>
      <RangeCalendar.YearPickerTriggerHeading />
    </RangeCalendar.YearPickerTrigger>
    <RangeCalendar.NavButton slot="next" />
  </RangeCalendar.Header>
  <RangeCalendar.Grid>
    <RangeCalendar.GridHeader>
      {(day) => <RangeCalendar.HeaderCell>{day}</RangeCalendar.HeaderCell>}
    </RangeCalendar.GridHeader>
    <RangeCalendar.GridBody>{(date) => <RangeCalendar.Cell date={date} />}</RangeCalendar.GridBody>
  </RangeCalendar.Grid>
  <RangeCalendar.YearPickerGrid>
    <RangeCalendar.YearPickerGridBody>
      {({ year }) => <RangeCalendar.YearPickerCell year={year} />}
    </RangeCalendar.YearPickerGridBody>
  </RangeCalendar.YearPickerGrid>
  <RangeCalendar.MonthPickerGrid />
  <RangeCalendar.TodayButton />
</RangeCalendar>
```

## Values

A range is `{ start, end }`, two of `@internationalized/date`'s days. Each one's `toString()` is
Gregorian ISO 8601 whatever calendar drew it: keep and send those.

## Accessibility

Each day is read with its full date and whether it is in the range, its start or its end. Name the
calendar with `aria-label` for what the span is for.

## Styling

`.range-calendar` with the Calendar's elements under its own name; a cell's `[data-selected]`,
`[data-selection-start]` and `[data-selection-end]` round the range's ends. The band is
`--range-band`, the brand's saffron-200 (800 in dark).
