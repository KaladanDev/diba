# Toolbar

A row of controls that belong together, which the Tab key reaches once and the arrow keys move
along: the bulk actions over a list's chosen rows, an editor's formatting.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Actions over what is chosen,** such as printing labels for three orders at once.
- **A set of tools,** such as bold, italic and a link over a description.
- **How a list is shown,** such as grid or list, and its sort.

Not for a page's few actions at the end of its title: buttons are enough. Not for a choice that is
one value: use a ToggleButtonGroup on its own.

## Import

```tsx
import { Button, Separator, Toolbar } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Toolbar aria-label="Bulk actions">
  <Button variant="secondary">Print labels</Button>
  <Button variant="secondary">Mark shipped</Button>
  <Separator />
  <Button variant="danger-soft">Delete</Button>
</Toolbar>
```

Its controls are 8 apart. A Separator in it runs across it, whatever it is told: down in a row,
half its height, and across in a column, half its width.

## Accessibility

It is a `toolbar`, named by its `aria-label`. Tab reaches its first control and leaves after it;
the arrow keys move from control to control, as the page reads, so on a Persian page the left
arrow moves onward.

<Keys
  rows={[

    ['ArrowDown ArrowUp', 'The same, in a column.'],
    ['Home End', 'To the first or the last control.'],
    ['Tab', 'Out of the toolbar.'],
