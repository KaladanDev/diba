# Text

Words in the type scale: a size, a weight and a colour that mean the same wherever they are used,
so a note is a note and a figure a figure on every page.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## When to use it

- **Words outside a component that sets its own,** such as a figure on a card or a note under a
  heading.
- **A heading of your own,** with `as="h2"` and a size.

Not for a field's label or description: Label and Description set theirs. Not for a link: use a
Link.

## Import

```tsx
import { Text } from '@kaladan/diba-react'
```

## Anatomy

```tsx
<Text size="sm" tone="muted">Sales today</Text>
<Text as="h2" size="xl" weight="semibold">Today's orders</Text>
```

## Accessibility

Its element is what a screen reader hears: a heading with `as="h2"`, a paragraph with `as="p"`.
Don't make words a heading only for their size.

## As a block

It draws with its own styles, so a page needs no utility classes for it. A tree's Text draws the
same scale and colours, on the web and in Flutter. It also shows a
`number` in the reader's digits and currency, clamps to `maxLines`, and takes a `headingLevel`.
